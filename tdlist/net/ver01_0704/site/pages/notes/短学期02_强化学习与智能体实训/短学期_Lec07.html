一句话：DDPG = 确定性 Actor + Critic，用 replay + target 学连续控制。

随机策略的痛点

REINFORCE / 朴素策略梯度：

  1. 步长难定：一步更新过大 → 策略变差 → 后续轨迹质量崩坏（「一步踩空掉下山」）。
  2. 分布漂移：多步更新后，用于估梯度的轨迹来自旧策略 ，与当前 差越来越大（离策略偏差）。

因此需要显式约束「新旧策略别差太远」——这就是 TRPO / PPO 的动机。

PPO：近端策略优化

OpenAI（2017）提出，在易实现、样本效率、调参难度之间折中，成为深度 RL 最常用基线之一。

相对 TRPO 的不足与改进

TRPO 痛点PPO 做法

约束优化难解一阶梯度 + 简单目标，无需二阶 / CG
—常用多步 TD / GAE 估优势

裁剪目标（Clipped Surrogate）

解读（ 常见 ）：

情形行为
正常更新： 提高概率， 降低概率
且 已过度抬高该动作 → 梯度截断，不再继续推大
且 已过度压低 → 截断，避免继续压

本质：用 importance ratio 的范围限制「每轮策略能改多大」。

另一种形式：自适应 KL 惩罚

按实测 KL 相对目标 动态调 （过大则增大惩罚，过小则减小）。

  1. 并行 个 Actor 用 采 步
  2. 算 （多步 TD / GAE）与裁剪损失
  3. 多 epoch mini-batch 更新 ，再令

分布式：DPPO

角色职责
Worker并行采轨迹 / 算梯度
Chief聚合（平均）梯度，更新全局策略再下发

可并行点：不同轨迹采集相互独立；满足条件后可不阻塞全部轨迹再更新。

一句话：PPO ≈「用 clip 的 ratio 代替 TRPO 的硬 KL 约束」——稳、快、好实现。

方法对照与总结

方法策略类型核心稳定手段典型场景
DDPG确定性 Replay + 目标网 + 动作噪声连续控制
TRPO随机KL 硬约束 + 二阶近似 / 线搜索理论保证强，实现重
PPO随机Clip ratio（或 KL 惩罚）通用强基线
SAC随机（最大熵）熵温度 + soft Q + replay连续控制、探索敏感任务

总结口径（课件）：

  1. 连续确定性策略：Critic 对动作求导，再链式传到 Actor。
  2. 神经网络策略步长过大 → 策略变差 → 数据质量塌陷。
  3. TRPO 用 KL 限制一步更新，稳步抬升。
  4. PPO 限制 importance ratio 范围，构造稳定可优化的下界目标——当前最常用的深度策略梯度算法之一。
