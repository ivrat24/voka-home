## 具身智能概念简介

#### 什么是具身智能？

**具身智能（Embodied Intelligence）** 指基于**物理实体**进行感知和行动的智能系统：智能体通过与环境交互获取信息、理解问题、做出决策并执行动作，从而产生智能行为与适应性。

**关键词**：物理实体、感知、行动。

与纯“大脑在缸里”的离线模型不同，具身系统必须处理：
- 连续时间动力学
- 传感器噪声与延迟
- 执行器饱和、摩擦、接触力
- 安全约束

#### 为什么需要“具身”？

**Held & Hein 实验（1963）**：两只幼猫接收**完全相同**的视觉信息，但只有**主动行走**的猫能学会正常行走；被动移动的猫丧失行走能力。

**启示**：智能不仅来自观察，还来自**主动运动与感知的耦合**——第一人称经验不可替代。

| 视角 | 含义 | 典型数据 |
|------|------|----------|
| **第一人称智能** | 机器人自主感知世界、交互、完成复杂行为 | 本体感知、视觉、力觉轨迹 |
| **第三人称智能** | 人类标注标签，告诉模型“这是什么” | 分类数据集、人工示范 |

RL 在具身场景下天然是**第一人称**：策略 \(\pi(a|s)\) 在自身传感器流上闭环决策。

#### 核心挑战

| 挑战 | 说明 | 与 RL 的关系 |
|------|------|----------------|
| **采样效率低** | 真机交互昂贵；RL 常需百万～千万步 | 仿真并行 + 离策略算法 |
| **安全问题** | 试错可能损坏机器人或环境 | 先在 Sim 训练，再谨慎 Sim2Real |
| **Sim–Real 差距** | 动力学、摩擦、延迟不一致 | 域随机化、系统辨识、微调 |

#### 四条迁移路径

```
Real2Sim   从真实数据校准仿真模型
Sim2Real   仿真训练 → 真机部署（最常用）
Sim2Sim    不同仿真器之间迁移
Real2Real  真机到真机（硬件更换、环境变化）
```

## 具身智能仿真平台

仿真器是具身 RL 的“健身房”：可并行、可重置、可域随机化。

| 平台 | 定位 | 特点 | 典型用途 |
|------|------|------|----------|
| **MuJoCo** | 通用接触动力学引擎 | Multi-Joint dynamics with **Contact**；快速精确 | 机械臂、灵巧手、腿足 |
| **Isaac Gym** | NVIDIA RL 专用 | **GPU 大规模并行**仿真；凸分解；域随机化 | 四足、大批量 PPO |
| **Isaac Lab** | 模块化机器人学习框架 | 基于 Isaac Sim；逼真渲染 + 高速仿真 | 统一研究流水线 |
| **SAPIEN** | 精细操作仿真 | 大规模铰接物体数据集；部件级理解 | 抓取、桌面操作 |
| **Habitat-Sim** | 室内移动操作 | 3D 扫描 / CAD；Bullet 刚体；多传感器 | 导航、移动机械臂 |

#### 选型速查

| 任务类型 | 推荐平台 |
|----------|----------|
| 接触丰富、关节多 | MuJoCo / Isaac |
| 需上万并行环境 | Isaac Gym / MuJoCo Warp |
| 桌面铰接物体 | SAPIEN |
| 室内导航 + 操作 | Habitat-Sim |

## 域随机化与 PPO（具身 RL 基础）

#### 域随机化（Domain Randomization）

在仿真中**随机采样**物理/视觉参数，使策略对模型误差鲁棒：

| 随机化对象 | 示例 |
|------------|------|
| 动力学 | 质量、摩擦、阻尼、电机增益 |
| 几何 | 连杆长度、碰撞体大小 |
| 传感 | 观测噪声、延迟、丢包 |
| 环境 | 地面高度、外力扰动 |

Dactyl 表明：**随机化越充分，Sim 训练越久，但 Real 成功率越高**。

#### PPO 在具身场景中的角色

本讲多数工作（Dactyl、HINF、BeamDojo、PIM 一阶段）底层为 **PPO** 或其在连续控制上的变体：

\[
L^{\text{CLIP}} = \mathbb{E}\left[\min\left(r_t(\theta)\hat{A}_t,\ \text{clip}(r_t(\theta),1-\epsilon,1+\epsilon)\hat{A}_t\right)\right]
\]

| 具身特点 | 对 PPO 的影响 |
|----------|----------------|
| 连续高维动作 | 高斯策略 \(\pi_\theta(a|s)=\mathcal{N}(\mu_\theta(s),\Sigma)\) |
| 长 horizon | 需 GAE、episode 截断、奖励缩放 |
| 并行仿真 | Isaac / Warp 提供大批量 on-policy 样本 |
| 安全 | 动作限幅、扭矩惩罚、终止惩罚 |

**与 Lec03 衔接**：Q 网络用于离散/离线；**腿足、灵巧手控制**更常用 **PPO / SAC** 等策略梯度方法。

#### 教师–学生蒸馏（通用模板）

```
[Sim + 特权观测] --RL--> 教师 π_T(a | s_priv)
                              |
                    行为克隆 / KL 蒸馏
                              v
[Sim/Real +  onboard 传感] --> 学生 π_S(a | s_obs) --微调--> 真机
```

| 阶段 | 观测 | 目的 |
|------|------|------|
| 教师 | 地形高度图、真实摩擦、物体位姿 | 学高质量行为 |
| 学生 | IMU、关节编码器、含噪激光 | 可部署 |
| 微调 | 同学生 + 少量真机成功轨迹 | 弥合 Sim2Real |

四足「地形解码器」、Dactyl「状态策略 + 视觉位姿 CNN」均属此模板。

## 机械臂与灵巧手

#### OpenAI Dactyl（魔方灵巧操作）

**方法**：PPO + **域随机化（Domain Randomization）**，无需人类标注从零学习。

**流水线**：
1. 构建大规模仿真，对机器人–方块物理参数随机化
2. RL 训练**转方块到目标位姿**的策略（状态含方块位姿）
3. 训练 CNN：图像 → 方块位姿估计
4. **串联**两模块，部署到真实 **Shadow Hand**

**硬件**：Shadow 灵巧手 + PhaseSpace 动捕 + Basler RGB 相机。

**代价**：未随机化 Sim 约 **3 年**模拟时间；全随机化约 **100 年**模拟时间——说明**探索 + 随机化**是 Sim2Real 核心成本。

#### RoboPianist（弹钢琴）

- 88 键电子琴建模为线性弹簧
- 双手 Shadow 灵巧手按乐谱按键轨迹演奏
- 能力：跨键盘弹奏、左手和弦、右手颤音（相邻键快速交替）

#### Sim2Real 难点（课堂总结）

| 问题 | 表现 |
|------|------|
| 泛化性不足 | 训练场景单一，真机失效 |
| Sim–Real 差距 | 摩擦、质量、延迟不一致 |
| 视觉误差 | 位姿估计漂移导致闭环失败 |

#### 教师–学生 + 真机微调

1. **Sim 中 RL 训练教师策略**：生成高质量轨迹与动作数据集
2. **蒸馏学生策略**：用教师数据监督学习
3. **真机收集少量成功轨迹**，对学生**微调**

**部署问题**：失误恢复弱、控制频率不足、质心偏移。

#### 仿真训练的设计要点

- **初始状态分布**：辅助探索（避免一直从不可行姿态开始）
- **状态信息**：适度使用特权信息（教师）再蒸馏到视觉学生
- **灵巧手任务**：触觉与视觉分离时，纯物理 Sim + 域随机化**不足以**完全弥合差距
- **动态技能**（转笔）：遥操作 / 模仿学习几乎不可行，**Sim RL 探索轨迹**至关重要
- **好消息**：仅需**少量**真机成功轨迹即可微调适应真实物理

#### SERL（Sample-Efficient RL）

开箱即用机器人 RL 套件：
- 离策略、样本高效算法
- 多种奖励设定
- 主流机械臂先进控制器

**任务**：PCB 组装、线缆布设、物体搬运；训练 **25–50 分钟**，高成功率与鲁棒性。展示含外部干扰的实机装配。

## 足式与人型机器人

#### 教师–学生 + 地形估计（四足）

1. RL 训练可访问**仿真特权信息**的**教师策略**
2. **蒸馏**为学生：模仿教师动作 + 从含噪观测重建状态
3. 学生含**地形解码器**，估计地形轮廓
4. **零样本**部署真机，使用本体高程地图采样

**噪声课程**：
- **大偏移**：位姿漂移 / 可变形地面
- **强噪声**：遮挡 / 传感器故障导致地形缺失

学生信念编码器：**循环核心 + 注意力门**，融合本体与外感知。

#### HIMLoco（内模 + 对比学习）

- **内模控制**：不显式建模干扰，用内部模型估计系统响应与干扰 → 增强闭环稳定性
- 输入：本体感知历史 + 状态估计
- **显式**线速度估计 + **隐式**未来响应（对比学习损失）

#### HINF（对抗式域随机化 + H∞ 控制）

**问题**：训练全程从**固定均匀分布**采样外力，无法针对策略薄弱环节。

**思路**：同时训练**运动策略**与**外力干扰器**；运动策略用 **PPO**；引入 **H∞ 约束**稳定训练。

**经典 H∞ 框架**：
- \(G\)：受控对象；\(u\)：控制输入；\(y\)：可测输出
- \(w\)：未知干扰；\(z\)：需最小化的误差输出
- 目标：设计控制器使闭环稳定，且 \(\|T_{wz}\|_\infty\) 最小（扰动 \(w\) 到误差 \(z\) 的增益有界）

**与 RL 结合**：将 H∞ 型损失并入策略优化；\(C\) 为预期与实际性能差距；简化为求 **η-optimal** 策略——干扰器在强度上限内最大化对策略性能的削弱。

**结果**：连续干扰下 HINF 仍鲁棒；无 H∞ 损失时简单对抗训练易失败。

#### H∞ 与 RL 目标（简化理解）

将「性能下降」视为扰动 \(w\) 经闭环传递函数 \(T_{wz}\) 产生的误差 \(z\)：

\[
\min_\pi \max_{\|w\|\le\eta} J(\pi, w) \quad \Leftrightarrow \quad \text{求 }\eta\text{-optimal 策略}
\]

**干扰器**与**策略**对抗训练：干扰器专找策略弱点施力，策略在 H∞ 正则下保持闭环稳定——比「从固定均匀分布采样外力」更有针对性。

#### PIM（人型复杂地形运动）

- 带**外感知**的人型运动策略框架
- **数小时**一阶段训练 → **零样本**硬件部署
- 整合**激光雷达高程地图**，无需历史视觉嵌入
- 实机：全尺寸 **H1** 攀 15 cm 台阶、跨间隙；**GR1T2** 部署
- 感知整合进**状态预测器**；单线雷达地图坐标系与躯干初始对齐、固定世界系

#### BeamDojo（稀疏落足点）

- 即插即用：在平地步态基础上跨越**稀疏立足点**地形
- **稠密落足点奖励**（统计采样）约束足端位置
- **双 Critic**：步态奖励 vs 落足点奖励解耦
- **孪生地形二阶段**：安全平地练规划 → 稀疏地形微调

#### HOMIE（半自主遥操作）

- 协调**全身控制** + 高接触频次操作
- 外骨骼 + 动作手套 → 同构映射到人型机器人；Wi-Fi 通信
- 三踏板：前后 / 躯干高度 / 转向；模式切换按钮
- RL 训练：在变上半身姿态下完成下蹲与行走

#### HoST（跌倒恢复）

- 任务分**三阶段**，每阶段激活对应奖励；**多 Critic + 奖励分组**
- 盆骨上施加**课程学习**垂直拉力促进探索
- **动作重缩放**收紧输出边界，限制力矩与速度；平滑正则减轻振荡
- 多样化起始地形 + 域随机化

## 人型机器人场景交互

#### UniHSI（LLM 驱动的统一交互框架）

**首个**大语言模型驱动的人型场景交互框架。

**核心建模**：将交互表示为**接触链（Contact Chain）**——用人体与物体各部分的接触关系描述行为。

**架构**：
```
语言指令 → [上游 LLM 规划器] → 接触链任务计划
                                    ↓
                          [下游 RL 运动控制策略] → 人型机器人执行
```

**能力**：
- 长程交互、多物品交互
- 同一物品多样化交互方式
- 基于 LLM 的**多智能体**交互

#### 接触链示例

「把桌上的杯子拿到柜子里」可分解为接触序列：

```
(右手, 杯子) → (右手+杯子, 移动) → (杯子, 柜子内) → (释放)
```

LLM 将自然语言转为此类**接触链计划**；下游 RL 控制器负责满足每个接触约束下的**平衡与步态**。

**与 RL 课程衔接**：Lec03 序列建模 + 本讲运动控制 → **高层规划（LLM）+ 低层 RL** 分层架构。

## 小结与衔接

| 概念 | 要点 |
|------|------|
| 具身智能 | 物理实体 + 感知行动闭环；第一人称经验 |
| 仿真平台 | MuJoCo / Isaac / SAPIEN / Habitat 分工不同 |
| 机械臂/灵巧手 | PPO + 域随机化；教师–学生 + 少量真机微调 |

**向下衔接**：
- 函数逼近（Lec03）→ 高维连续状态上的 PPO / 离策略 RL
- 本讲 Sim 训练 → 后续真机需注意安全、样本效率与 Sim2Real 管线
- 实验课 Warp 并行 → 与 Isaac Gym「大批量采样」同一思路

**一句话**：具身智能 = **在仿真里大胆试错，在真机上谨慎微调**；RL 提供探索，仿真提供规模，域随机化与蒸馏提供桥梁。
