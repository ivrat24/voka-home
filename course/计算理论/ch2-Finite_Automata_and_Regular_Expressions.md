# ch2-Finite Automata and Regular Expressions

> Chapter 2 核心知识整理（突出定义、等价关系与判定方法；公式按站点 KaTeX 规范书写）

**约定：** 用 **DFA**、**NFA** 分别指确定性 / 非确定性有限自动机；空串记 \(e\)（教材亦常作 \(\varepsilon\)）。

---

## 1. Deterministic Finite Automata（DFA）

### 1.1 直观模型

有限自动机读**输入纸带**上的字符串，最终只给出「是否接受」的指示：

| 部件 | 含义 |
|------|------|
| **输入纸带** | 分成方格，每格一个符号 |
| **有限控制** | 任意时刻处于有限多种**内部状态**之一的「黑盒」 |
| **读头** | 感知当前方格符号；每步读完后**右移一格** |

运行过程：

1. 读头在最左格，控制处于**初始状态**  
2. 每步：读符号 \(a\)，由当前状态与 \(a\) 唯一进入下一状态，读头右移  
3. 读完输入后：若停在**最终状态**集合中的某状态，则**接受**该串  
4. 机器接受的语言 = 它所接受的全部字符串之集  

```diagram
flow
初始：(s, w) → 逐步 ⊢ → (q, e)
若 q ∈ F 则接受 w；否则拒绝
```

### 1.2 形式化定义

**定义.** 确定性有限自动机是五元组

\[
M = (K,\Sigma,\delta,s,F)
\]

其中：

| 符号 | 含义 |
|------|------|
| \(K\) | 状态的有限集 |
| \(\Sigma\) | 字母表 |
| \(s \in K\) | **初始状态**（start state） |
| \(F \subseteq K\) | **最终状态**集 |
| \(\delta\) | **转移函数**：\(K \times \Sigma \to K\) |

若当前状态 \(q \in K\)、读到 \(a \in \Sigma\)，则下一状态 \(\delta(q,a) \in K\) **唯一确定**。

### 1.3 配置与一步产生

- **配置** \(C = (q,w)\)：当前状态 \(q\) + **剩余**未读串 \(w\)  
- \((q,w) \vdash_M (q',w')\)（一步产生）当且仅当：存在 \(a \in \Sigma\)，使得 \(w = aw'\) 且 \(\delta(q,a) = q'\)  
- \(\vdash_M\) 实际是从 \(K \times \Sigma^+\) 到 \(K \times \Sigma^*\) 的函数：除形如 \((q,e)\) 的配置外，每配置有**唯一**下一配置  
- \((q,e)\)：已读完输入，停机  
- \(\vdash_M^*\)：\(\vdash_M\) 的**自反传递闭包**（0 步或多步）

**接受：** \(w \in \Sigma^*\) 被 \(M\) 接受，当且仅当存在 \(q \in F\)，使得

\[
(s,w) \vdash_M^* (q,e)
\]

**语言：** \(L(M) = \{ w \in \Sigma^* : w \text{ 被 } M \text{ 接受} \}\)

**图形化：** 用**状态图**（state diagram）画状态与标号边。

### 1.4 方法补充：DFA 最小化（考点向）

> 朋辈辅学常考「最小化」。核心思想：合并**不可区分**状态。

1. **去掉不可达状态**（从 \(s\) 出发到不了的状态）  
2. **划分可区分类**（表填充 / 等价类划分）：  
   - 若 \(p \in F\)、\(q \notin F\)（或反之），则 \(p,q\) **可区分**  
   - 若存在 \(a\) 使 \(\delta(p,a)\) 与 \(\delta(q,a)\) 已可区分，则 \(p,q\) 可区分  
3. 同一等价类内状态可合并；得到的最小 DFA **状态数最少**且 \(L\) 不变  

**考试写答案：** 给出最小化状态图 + 简述「终态/非终态先分，再按符号传播可区分性」。

## 2. Nondeterministic Finite Automata（NFA）

### 2.1 非确定性含义

下一状态**不完全**由「当前状态 + 输入符号」唯一决定：同一 \((q,a)\) 可有多个合法后继；还可有**不读输入**的 \(e\)-转移。  
这是对 FSM 的**记法推广**：描述常更简洁；且 **NFA 与 DFA 能力等价**。

**例子（对照）：** 语言 \(L = (ab \cup aba)^*\) 的 DFA 状态图通常更「胖」，NFA 更「瘦」——同一语言，NFA 用分支表达「猜」走哪条 \(ab\) / \(aba\) 分解。

### 2.2 形式化定义

**定义.** NFA 是五元组

\[
M = (K,\Sigma,\Delta,s,F)
\]

| 符号 | 含义 |
|------|------|
| \(K,\Sigma,s,F\) | 同 DFA |
| \(\Delta\) | **转移关系**：\(\Delta \subseteq K \times (\Sigma \cup \{e\}) \times K\) |

- 元组 \((q,u,p) \in \Delta\) 称为一次**转移**（\(u \in \Sigma \cup \{e\}\)）  
- **配置**仍是 \(K \times \Sigma^*\) 的元素  
- \((q,w) \vdash_M (q',w')\) 当且仅当：存在 \(u \in \Sigma \cup \{e\}\) 使  
  - 若 \(u \in \Sigma\)：\(w = uw'\) 且 \((q,u,q') \in \Delta\)  
  - 若 \(u = e\)：\(w = w'\) 且 \((q,e,q') \in \Delta\)  
- \(\vdash_M\) **不必是函数**（可一对多）  
- 接受条件同 DFA：\(\exists\, q \in F,\ (s,w) \vdash_M^* (q,e)\)

**注意：** 串被接受 ⟺ **存在**一条从 \((s,w)\) 到某 \((q,e)\)（\(q \in F\)）的计算路径（「猜对」即可）。

### 2.3 DFA 是 NFA 的特例

NFA 是**确定的**，当且仅当：

1. \(\Delta\) 中**没有**形如 \((q,e,p)\) 的转移；且  
2. \(\forall q \in K,\ \forall a \in \Sigma\)，**恰好**存在一个 \(p\) 使 \((q,a,p) \in \Delta\)  

此时 \(\Delta\) 可改写成函数 \(\delta: K \times \Sigma \to K\)。

### 2.4 等价性

两台自动机（DFA 或 NFA）**等价** ⟺ \(L(M_1) = L(M_2)\)。

**定理.** 对每一个 NFA，存在一个等价的 DFA。

### 2.5 方法补充：子集构造（NFA → DFA）★

**目标：** 用「当前可能处于的状态集合」做 DFA 的单个状态。

设 NFA \(M = (K,\Sigma,\Delta,s,F)\)。

1. **\(e\)-闭包** \(E(Q)\)：从集合 \(Q\) 出发，只走 \(e\)-边能到达的全部状态（含自身）  
2. DFA 状态集 \(\subseteq 2^K\)；初始状态 \(s' = E(\{s\})\)  
3. 对 DFA 状态 \(A \subseteq K\)、符号 \(a \in \Sigma\)：

\[
\delta'(A,a) = E\!\left(\{ p : \exists q \in A,\ (q,a,p) \in \Delta \}\right)
\]

4. DFA 终态：凡与 \(F\) **相交非空**的子集  

**复杂度直觉：** 最坏 \(2^{|K|}\) 个 DFA 状态；考试常只构造**可达**子集。

```diagram
flow
NFA 状态 q ↦ DFA 用「集合」记住所有可能的 q
读 a：对集合里每个状态取 a-后继，再取 e-闭包
终态：集合里只要含原 NFA 的某个终态即可
```

## 3. Regular Expressions（正则表达式）

### 3.1 动机

计算理论的中心问题之一：用**有限规范**表示语言。  
有限语言可穷举；无限语言需要「表达式」一类有限描述。  
凡有限表示，只能描述**可数**多个语言——「不可数那么多」的语言无法被有限表示。

### 3.2 语法（归纳定义）

字母表 \(\Sigma\) 上的**正则表达式**是 \(\Sigma \cup \{(\,),\varnothing,\cup,{^*}\}\) 上的串，按下列规则生成：

1. \(\varnothing\) 与每个 \(a \in \Sigma\) 是正则表达式  
2. 若 \(\alpha,\beta\) 是，则 \((\alpha\beta)\) 是（**拼接**）  
3. 若 \(\alpha,\beta\) 是，则 \((\alpha \cup \beta)\) 是（**并**）  
4. 若 \(\alpha\) 是，则 \(\alpha^*\) 是（**克莱尼星号**）  
5. **仅**由以上得到者才是正则表达式  

### 3.3 语义 \(L(\alpha)\)

| 表达式 | 语言 |
|--------|------|
| \(L(\varnothing) = \emptyset\) | 空语言 |
| \(L(a) = \{a\}\)（\(a \in \Sigma\)） | 单符号 |
| \(L((\alpha\beta)) = L(\alpha)\,L(\beta)\) | 拼接 |
| \(L((\alpha \cup \beta)) = L(\alpha) \cup L(\beta)\) | 并 |
| \(L(\alpha^*) = L(\alpha)^*\) | 星号 |

**优先级：** \({^*} >\) 拼接 \(> \cup\)（可省多余括号）。  
同一语言可对应**无穷多个**正则表达式。

### 3.4 正则语言（表达式视角）

\(\Sigma\) 上的**正则语言**类：所有满足 \(L = L(\alpha)\)（\(\alpha\) 为正则表达式）的语言 \(L\)。  
等价刻画：在有限集 \(\{\{\sigma\} : \sigma \in \Sigma\} \cup \{\emptyset\}\) 上，关于**并、拼接、克莱尼星号**的**闭包**。

## 4. Regular Languages（正则语言 · FA 视角）

### 4.1 另一等价定义

正则语言 = 被某个 FA（DFA 或 NFA）接受的语言。

**定理.** 语言正则 ⟺ 被某个有限自动机接受。

### 4.2 闭包性质 ★

被 FA 接受的语言类在下列运算下**封闭**：

| 运算 | 直觉构造 |
|------|----------|
| **并** | 新初态 \(e\)-到两机初态；终态 = 两机终态之并 |
| **拼接** | 前机终态 \(e\)-到后机初态 |
| **克莱尼星号** | 新初态（兼终态）\(e\)-到原初态；原终态 \(e\)-回原初态 / 新初态 |
| **补** | DFA 终态与非终态对调（须先确定化） |
| **交** | \(L_1 \cap L_2 = \overline{\overline{L_1} \cup \overline{L_2}}\)，或乘积自动机 |

**方法提示：** 证明「某构造仍正则」时，优先写清「由谁通过哪条闭包得到」。

### 4.3 若干结论

- 单个正则语言 \(L \subseteq \Sigma^*\)（\(\Sigma\) 有限）必为可数集（因 \(\Sigma^*\) 可数）  
- **全体正则语言**构成的集合也可数（有限表示可枚举）  
- 对正则语言做**无限次**并 / 交 / 拼接，**不保证**结果仍正则  

### 4.4 正则 / 非正则例子（对照记）

**正则：**

| 语言 | 理由速记 |
|------|----------|
| \(\{a\}^*\) 或 \(\{a^n : n \ge 0\}\) | \(a^*\) |
| \(\{a\}^*\{b\}^*\) | \(a^*b^*\) |
| \(\{a^m b^n : m,n \ge 0\}\)，且 \(m,n\) **无额外关系**，或关系只在**有界**范围（如 \(m=n\) 且 \(n < 1000\)） | 有限记忆 / 有限例外可并入 FA |
| \(\{w^R : w \in L_0\}\)，\(L_0\) 正则 | 反转：NFA 反向边 + 初终态对调 |
| \(\{a^n : n \text{ 为偶数}\}\) | \((aa)^*\) |

**非正则：**

| 语言 | 直觉 |
|------|------|
| \(\{a^m b^n : m,n \ge 0\}\) 且 \(m,n\) **有无界关系**（如 \(m=n\)、\(m=2n\)、\(m>n\)） | 要记住任意多个 \(a\) |
| \(\{a_1^n a_2^n \cdots a_k^n\}\)（\(k \ge 2\) 同类） | 多段同步计数 |
| \(\{a^n : n \text{ 为素数}\}\) | 素数无「简单周期」 |
| \(\{ww^R : w \in \{a,b\}^*\}\) | 回文；CFL 但非正则 |
| \(\{ww : w \in \{a,b\}^*\}\)、\(\{wcw : w \in \{a,b\}^*\}\) | 需比对两半 |
| \(\{w\,\widehat{w} : \widehat{w}\text{ 为 }w\text{ 的 }a\!\leftrightarrow\!b\text{ 翻转}\}\) | 需逐位相关 |

## 5. Languages that Are and Are Not Regular

### 5.1 两个直观（非正式）

1. **有限、预先固定的记忆**：从左到右扫描时，判定所需「内存」只依赖语言本身，不随输入任意增长。  
   - 故 \(\{a^n b^n : n \ge 0\}\) 非正则：到 \(a\)/\(b\) 分界处无法用有限状态记住任意多个 \(a\)。  
2. **无限正则语言必有「可泵」的重复结构**：来自状态图中的**环**或正则表达式中的 \({^*}\)。  
   - 故 \(\{a^n : n>1\text{ 为素数}\}\) 非正则：素数集无简单周期性。

正式证明需要更精确的工具 ↓

### 5.2 泵引理（Pumping Lemma）★

**定理.** 设 \(L\) 正则。则存在整数 \(n \ge 1\)（**泵长度**），使得任意 \(w \in L\) 且 \(|w| \ge n\)，均可写成 \(w = xyz\)，满足：

1. \(y \ne e\)  
2. \(|xy| \le n\)  
3. \(\forall\, i \ge 0,\ xy^i z \in L\)

**地位：** 正则 ⟹ 可泵；**可泵 ⇏ 正则**（必要不充分）。  
**主要用途：** 用**逆否**证明「非正则」。

### 5.3 方法补充：用泵引理证非正则（标准模板）

**目标：** 证 \(L\) 非正则。

1. **反证**假设 \(L\) 正则，取泵长度 \(n\)  
2. **选挑衅串** \(w \in L\)，\(|w| \ge n\)（让「必须记住的量」落在前 \(n\) 个符号里）  
3. 对**任意**满足 \(w=xyz\)、\(y\ne e\)、\(|xy|\le n\) 的分解，指出某个 \(i\) 使 \(xy^i z \notin L\)  
4. 与泵引理矛盾 ⟹ \(L\) 非正则  

**选串技巧：**

| 语言类型 | 常用 \(w\) |
|----------|------------|
| \(\{a^k b^k\}\) | \(a^n b^n\)（\(y\) 只能在 \(a\) 段） |
| \(\{a^{k} b^{2k}\}\) 等 | 让 \(|xy|\le n\) 逼 \(y\) 全是 \(a\) |
| \(\{ww\}\) | \(a^n b a^n b\) 等对称串 |
| 素数长度 | \(a^p\)（\(p\) 为 \(>n\) 的素数），泵坏素性 |

### 5.4 正则性判定总表（期末高频）

**不存在**判定「任意语言是否正则」的通用算法。

| 方向 | 可用工具 |
|------|----------|
| **证正则** | 语言有限；构造 FA；写正则表达式；用闭包从已知正则语言推出 |
| **证非正则** | 泵引理；反证「若正则则…矛盾」；论证不存在 FA；**闭包技巧**：取已知正则 \(R\)，若 \(L \cap R\)（或与补、同态等组合）非正则，则 \(L\) 非正则（注意：交为正则**不能**推出 \(L\) 正则） |

```diagram
flow
证正则：构造 / 表达式 / 闭包（正向）
证非正则：泵引理 或 「L ∩ 正则 = 非正则」反推
```

## 6. 例题精讲（方法落地）

### 6.1 判断是否正则

\[
L = \{ a^i b^j c^k : i+j \not\equiv k \pmod{3},\ i,j,k \in \mathbb{N} \}
\]

**结论：\(L\) 是正则语言。**

**思路（推荐写法）：**

1. 只关心三个计数对模 3 的余数，状态空间有限：可用 DFA 状态记 \((i \bmod 3,\ j\bmod 3)\) 在读 \(c\) 前的信息，或更干净地记「已读部分对模 3 的贡献」。  
2. 一种标准构造：先认

\[
L_0 = \{ a^i b^j c^k : i+j \equiv k \pmod{3} \}
\]

   用 DFA 维护读完后的 \(i+j-k \bmod 3\)（读 \(a,b\) 时 \(+1\)，读 \(c\) 时 \(-1\)，非法顺序进陷阱）。\(L_0\) 正则。  
3. 合法形如 \(a^*b^*c^*\) 的串之集 \(R = L(a^*b^*c^*)\) 正则。  
4. \(L = R \cap \overline{L_0}\)（在全集 \(\Sigma^*\) 或先交 \(R\) 再补相对 \(R\)——考试写清论域）。由闭包知 \(L\) 正则。  

**易错点：** 「带不等式 / 模运算」≠ 非正则；**无界相等**（如 \(i=k\)）才常非正则，**模固定整数**通常正则。

### 6.2 快速自测清单

| 问题 | 答案要点 |
|------|----------|
| DFA 与 NFA 谁更强？ | **同等**（定理：NFA⇒等价 DFA） |
| \(e\)-边在哪边允许？ | 仅 NFA |
| 正则 ⟺ ？ | 正则表达式 / DFA / NFA 三者等价 |
| 泵引理能证正则吗？ | **不能**（只作非正则的必要方向） |
| \(\{a^n b^n\}\) | 非正则；泵或「无限记忆」直觉 |
